# 组件库选型

记录日期：2026-11-04。初次检索连接失败，后续网络恢复，已查看以下原生库的官方仓库和说明。尚未在本项目中安装或验证其与固定 MyGo 快照的编译兼容性。

## 优先评估的 MyGo 原生库

| 库 | 已确认的内容 | 本项目适用性 |
| --- | --- | --- |
| [Onevra](https://github.com/oneo-me/onevra) | MyGo 原生主题控件、窗口外壳、Lucide 图标；官网列有 FloatingButtonGroup、Settings、Sidebar、GridView 等组件 | 首选评估：统一工作台外壳、浮动工具栏、设置与历史列表；[官网交互展示](https://oneo-me.github.io/onevra/) |
| [uix](https://github.com/smallnest/uix) | shadcn/ui 风格的 MyGo 原生组件；按钮、工具栏、菜单、弹层、分栏、颜色选择等 | 备选：偏简洁、克制的工具界面，可配自定义玻璃容器 |
| [CrychicUI](https://github.com/ELY-Open-Source/CrychicUI) | 原生 Go 控件及动画、音效；提供 gallery | 适合作为补充参考；作者默认音效需评估是否适合常驻截图工具 |
| [mygo-platinum](https://github.com/firede/mygo-platinum) | 90 年代 Platinum 复古桌面风格 | 不优先用于此次现代毛玻璃方向 |

Onevra 官网和仓库的版本描述存在差异，且仓库提醒 Windows/Linux 仍需原生检查，因此接入前必须固定准确版本并运行对应平台测试。不能仅凭有演示就宣布三端稳定。

推荐先基于 Onevra 做同一张截图工具工作台的小样，并与 uix 进行视觉比较。没有必要同时引入所有库。原生组件库负责统一基础外观，画布和截图业务仍由本项目实现。

## 本地已确认的原生方案

MyGo 官方 Base 组件提供按钮、输入框、选择器、菜单、对话框、开关和标签页等行为，应用负责样式封装。依据为固定源码快照中的 `docs/ui/custom-widgets.md`。`plugins/glass` 可以为同一窗口内的工具条、浮层提供毛玻璃。

这些基础组件可以复用，但仍需要统一的视觉封装与布局设计。当前页面的排版和字体需要重新设计，增加透明度不能解决这些问题。

## 待评估的网页组件库

| 候选 | 方向 | 接入方式 |
| --- | --- | --- |
| [Fluent UI React](https://react.fluentui.dev/) | 系统工具、设置、菜单、桌面式工作台 | MyGo WebView；不能直接用于 `ui.View` |
| [shadcn/ui](https://ui.shadcn.com/docs) | 定制工具栏、弹层、设置界面 | React/Web；布局和视觉仍需设计 |
| [Radix Themes](https://www.radix-ui.com/themes/docs/overview/getting-started) | 统一的表单、列表和辅助面板 | React/Web；需评估主题和材质 |

上述是后续查看官方示例的候选，当前未验证最新版本或安装方案，不因此改架构或安装依赖。若采用 WebView，Go/MyGo 继续负责系统功能，设置和工作台可采用网页组件；截图覆盖层和贴图仍需验证焦点、透明和多屏行为。

当前优先继续原生路线，先验证 Onevra/uix 的依赖兼容性与实际 gallery。WebView 方案保留为后备，选型前保留当前原型。
