# 界面设计规范

本规范记录 2026-11-04 新确认的要求：Windows、macOS、Linux 桌面共用响应式界面，使用毛玻璃材质。取代前期“Linux 暂不承诺”的平台范围；各平台截图引擎仍需分别实现和验证。

最新视觉选择：用户选择“通透轻盈：浅色、更多半透明层次、柔和色彩”。新版使用浅蓝到淡绿的低对比工作区底色，侧栏浮起并使用磨砂材质，属性面板采用半透明的清晰表面。窗口内画布、图片与工具条分别成层；截图像素不施加模糊。下文早期“仅工具栏使用玻璃”的限制相应扩展为侧栏与浮动控件，仍保持统一关闭开关。

体验程序为 `screenpin-air.exe`，保留上一版 `screenpin.exe` 便于比较。此版未接入 Onevra，仍采用 MyGo 原生组件与 Glass。Windows 真实窗口验证、单元测试和三平台构建/静态检查已通过，macOS/Linux 尚未实机运行。

## 视觉方向

工作台以内容为中心：安静的浅灰画布、蓝灰色侧栏、清晰的图片边界、悬浮的磨砂工具条。毛玻璃集中在工具条和辅助导航，不把整张截图模糊化。品牌暂用“映刻 Screenpin”，后续可以更改。

颜色：纸白 #F8FAFC、画布 #E8EDF3、正文 #182434、辅助文字 #526376、主色 #2463EB、选中背景 #E4EDFF。暗色使用 #151C27、#202A38 与高对比浅色文字。普通文本对比度目标至少 4.5:1；不把透明度当作文字灰度。

字体用系统无衬线，中文自动回退。Windows 跟随系统中文字体，macOS 和 Linux 使用各自系统字体。字号以 13/14/17/22 为主，标签不小于 12 DIP。空间单位 4 DIP，主要间距 8/12/16/24；组件圆角按用途使用 6/10/14，不全部做成胶囊。

## 自适应布局

| 窗口内容宽度 | 布局 |
| --- | --- |
| ≥1180 DIP | 完整左导航、中央画布、右侧属性栏 |
| 820–1179 DIP | 紧凑左导航和画布，属性通过独立入口打开 |
| <820 DIP | 顶部紧凑导航，中央画布和可换行操作条 |

短窗口下压缩画布外围间距，辅助信息可滚动；不能裁掉导出、取消和关闭。窗口宽度不是屏幕物理像素，适配同时覆盖高 DPI 与系统文字大小。

## 材质分层

MyGo `plugins/glass` 处理同一窗口内已绘制内容的磨砂效果。这适用于画布上方的浮动工具条，计划默认开启。它不是桌面背景模糊。

系统窗口材质通过 MyGo Vibrancy 适配：Windows 评估 Acrylic，macOS 评估系统半透明材质，Linux 不承诺桌面背景模糊。低性能、关闭透明效果或高对比度环境使用不透明表面。关闭毛玻璃后布局、操作和文字对比不变。

不增加装饰性的光晕、彩色阴影或全屏渐变。工具图标使用一组线性 SVG，提供中文标签、提示和键盘焦点。

## 本次原型范围

工作台、图片预览、图片打开/复制/保存、实际置顶贴图、明暗外观、毛玻璃开关和三档布局。内置示例图只是演示素材。区域截图、OCR、长截图和录屏尚未接入，不把这些标为完成。

## 验证方式

Windows 实际运行并截图核对布局；通过 UI Tester 检查大中小尺寸的关键操作可见性；macOS/Linux 先做构建检查，真实窗口、字体、合成器与桌面能力分别等待对应设备验证。不能将跨平台构建成功称为各系统实际使用已验证。
