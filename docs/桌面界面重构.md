# 桌面界面重构 · 2026-11-05

## 方向

面向截图后图片处理和置顶对照的桌面工具。图像是主要内容，打开、粘贴、复制、保存和贴图是主要操作。移除启动示例图和独立贴图介绍页，避免功能演示页占据实际工作空间。

配色：背景 `#F7F8FA`、表面 `#FFFFFF`、正文 `#25282D`、次要文字 `#69707A`、边界 `#DEE1E5`、动作强调 `#2563EB`。Windows 使用 Microsoft YaHei UI，正文 13 DIP，辅助信息 11–12 DIP，页面标题 20 DIP。圆角 5 DIP，按钮高 30 DIP。

## 布局

```text
------------------------------------------------------
空白状态 / 图片预览 / 设置表单

------------------------------------------------------
缩小  比例  放大  适应                       复制  保存  贴图
状态                                              F1
```

顶部导航代替侧边大按钮；工作台工具固定在底栏，不覆盖图片。空白状态保留打开和粘贴的指引，输出操作禁用。棋盘格仅用于图片透明区域，画布使用中性纯色，取消图片装饰阴影。设置用同一字号体系和对齐的短输入框。

新用户默认关闭毛玻璃；已有配置保留。毛玻璃是外观浮动面板的可选效果，主体内容始终不透明。

## 验证

`go test .` 验证最小及其他窗口尺寸下的工具栏、标题栏系统按钮避让、图像信息、快捷键、配置、空图片操作保护；`go vet .` 检查通过。

Windows 真实窗口验证空白状态、剪贴板图片载入、缩放、深色外观、设置编辑、快捷键保存、重复组合键拒绝、恢复默认，以及系统组合键触发贴图。自动化在读取状态前请求新画面，避免读到旧帧。验证期间使用临时配置目录，截图为 `artifacts/workspace-empty.png`、`workspace-current.png`、`workspace-dark-current.png` 和 `hotkey-settings.png`。
