## 当前原型

2026-11-05：已加入外观设置持久化。深色外观和毛玻璃开关在修改后自动保存到系统用户配置目录下的 `Screenpin/settings.json`，下次启动恢复；Windows 通常为 `%APPDATA%\Screenpin\settings.json`。配置缺失使用默认浅色和开启毛玻璃；读取损坏配置或保存失败会在状态栏提示。配置通过临时文件写入后替换，避免直接截断原文件。已通过配置往返、损坏回退、界面开关保存、保存失败测试及 `go test .`、`go vet .`；此轮未进行真实桌面重启验收。

当前统一入口为 `screenpin-latest.exe`。已加入工作台快捷键和全局剪贴板图片贴图；按 F1 或点击底部“快捷键”查看实际注册的组合键。默认全局 Ctrl/⌘+2，占用时尝试 Ctrl/⌘+Alt+2，全部不可用时显示失败，不修改其他应用的绑定。Linux Wayland 的全局绑定依赖桌面 portal 和安装配置，尚未实机验证。

工作台：Ctrl/⌘+O 打开、V 粘贴、C 复制、S 保存、P 贴图、+/− 缩放、0 适应、逗号打开设置。贴图窗口：Esc 或 Ctrl/⌘+W 关闭、Ctrl/⌘+C 复制。贴图也已改为融合式标题栏，保留系统按钮和顶部拖动。区域截图 Ctrl+1 尚未实现。

Windows 真实按键验证了复制/粘贴、F1 帮助、系统全局 Ctrl+2 创建贴图和 Esc 关闭；贴图截图为 `artifacts/pin-window.png`。测试与三端构建通过，macOS/Linux 尚未实机运行。

最新紧凑布局请运行 `screenpin-compact.exe`：默认 900×600 DIP，顶部压缩为 48 DIP，左侧为 60 DIP 导航；图像信息按需弹出。缩放、复制、保存、贴图集中到画布下方，不再遮挡图片。旧版保留作比较。新默认布局截图为 `artifacts/workspace-default.png`，已通过布局测试、信息面板测试和 Windows 真实窗口操作验证；Linux/macOS 构建通过。

## 结论

以 PixPin 3.6.6.0 的公开功能和使用流程为对标，开发一款 Go 为主、Windows 优先的桌面截图工具。最终覆盖截图、可编辑标注、悬浮贴图、本地 OCR、长截图、录屏、历史和分组，再推进翻译、表格与文档识别等高级能力。

“一模一样”落实为可逐项验证的功能和交互对齐。公开资料不能证明其内部实现、识别模型或所有细节；不能承诺识别结果和像素级界面完全一致。项目使用自己的名称、图标和代码。

## 技术决策

- 主语言：Go。首发：Windows 10 22H2 / Windows 11 x64。
- UI 候选：MyGo 原生 UI；必须先通过 Gate 0，固定提交版本，避免依赖持续变动的 main。
- 桌面捕获：静态截图先验证 Win32/GDI，持续捕获再评估 DXGI / Windows Graphics Capture。
- 本地 OCR：独立推理任务与可替换模型，验证 ONNX Runtime 路线；不把 Windows OCR 的免安装可用性当作既定事实。
- 录制编码：独立 FFmpeg 进程，原始帧和媒体数据不经 UI 消息通道传输。
- 存储：SQLite 元数据、文件保存原图与媒体、原子替换配置。

MyGo 提供窗口、绘图等基础，但截图覆盖层、外部桌面捕获、拼接、OCR 和录制仍然要开发。不能把框架未合并的截图 PR 算作现成能力。
