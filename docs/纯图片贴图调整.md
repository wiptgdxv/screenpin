# 纯图片贴图调整 · 2026-11-05

按最新要求，贴图浮窗只显示图片和右上角图钉图标。移除标题栏、文件名、底部提示、常驻文字按钮、原始像素按钮及系统窗口按钮。原始像素查看改用 Ctrl/⌘+0，Esc 和 Ctrl/⌘+W 关闭，Ctrl/⌘+C 复制。

窗口使用无边框透明面板，不显示任务栏项，按图片比例及显示器缩放设置尺寸。图像绘制使用 14 DIP 圆角剪裁，四角透明，不绘制背景边带。拖动图片移动窗口；原始像素模式下拖动平移内容。固定图标使用标准图钉造型，选中变蓝，再次点击取消固定。未固定时失焦关闭，固定后保持。

纯图片浮窗不设置系统毛玻璃背景，保持图片透明区域和圆角直接透明。控制面板及其他工具栏的毛玻璃功能保留。显示圆角不裁切或修改复制、保存的数据。

验证：

- `go test .`、`go vet .`。
- 布局测试确认没有文字控制条，四角 alpha 为 0，图片到达四边中点；图钉切换不改变原始 PNG。
- `scripts/verify-pin.ps1` 在 Windows 实际截图后验证：160×200 图片对应同尺寸浮窗，四角透明；真实鼠标拖动图片移动窗口；图钉固定、取消固定和点击外部关闭通过。
