# 后台截图开发记录 · 2026-11-05

主窗口调整为启动与设置面板。关闭按钮隐藏主窗口，托盘菜单提供区域截图、剪贴板贴图、显示面板、设置及退出。单实例锁将再次启动转交给运行实例；启动后隐藏是可记忆的设置，不操作系统自启动项。

Windows 原生 GDI 捕获整个虚拟桌面，捕获前隐藏主面板；独立线程显示冻结画面的框选覆盖层。坐标使用物理像素，框选支持反向拖动、边界裁剪、Esc / 右键取消和显示配置变化取消。成功后编码 PNG，并写入原始 PNG、DIB、CF_BITMAP 三种静态剪贴板表示；取消保留剪贴板。未载入图片时输出操作仍被保护。

快捷键配置新增区域截图（默认 Ctrl+1），沿用 Ctrl+2 贴图、F8 显示面板。旧配置缺少截图字段时补默认值，明确空值表示停用；注册占用和保存失败保留现有绑定。全局动作直接在应用主线程分发，独立捕获任务不阻塞设置与托盘。

全局毛玻璃由一个连续的原生背景提供，各子区域透明叠加；明暗模式及开关变化传播到已有贴图。Windows 窗口从创建时具备合成背景能力，初始选择纯色仍能随后开启效果。图片、PNG 数据和输出不随毛玻璃改变。

## 验证

- `go test .`：布局、空素材保护、配置往返、快捷键回滚、配置兼容，以及反向/负坐标/越界选区。
- `go vet .`：检查通过；原生调用包装使用 `go:uintptrescapes` 保持传入指针生命周期。
- `scripts/verify-capture.ps1`：临时配置目录中设置测试键，隐藏面板后实际发送系统按键，验证取消保留剪贴板、160×100 裁剪与实屏参考像素、原生富文本粘贴、后台贴图和唤回、关闭到托盘、二次启动转交、退出进程。
- `scripts/verify-glass.ps1`：实窗各区域透明度、设置、图片、贴图、明暗及开关回退。

实机环境为 Windows 单显示器 1920×1080。多屏、混合 DPI、HDR 与受保护窗口尚无实机验收；不能由坐标单元测试推断这些场景均已通过。macOS/Linux 保留可构建代码，区域截图明确提示尚未支持。标注、OCR、长截图和录屏仍待后续实现。
