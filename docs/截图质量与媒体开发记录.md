# 截图质量、临时贴图、滚动截图与录屏

日期：2026-11-05。当前状态以本文件和根目录 README 为准，早期开发记录中的未实现功能列表属于历史记录。

## 画质

桌面 GDI 采集使用物理坐标，BGRA 原始像素转为 RGBA，编码为原始尺寸 PNG。没有 JPEG、降采样或通过预览重新截图导出的环节。`quality_test.go` 对带行填充的高频彩色数据裁剪、转码、PNG 编解码后检查全部像素；原生验证窗口另检查 160×200 实屏 PNG 的所有像素。

主预览新增设备像素 `1:1`、整数像素对齐与拖动平移。适应窗口只是预览，默认显示「适应」，不再把适应比例标为原始大小。贴图不放大小图片，亦提供原始像素与拖动。复制和保存始终使用原图数据。

GDI SDR 8-bit 采集不等同于 HDR/受保护内容捕获；这些能力没有新增，也没有以放大像素冒充清晰度提升。

## 贴图

用户确认语义：贴图默认临时，失去焦点即关闭；点「常驻」后保留，再点取消常驻。区域截图与长图完成后，自动复制并按配置自动贴图，默认开启；配置缺失迁移为开启，明确关闭会保留。主控制面板仍是关闭到托盘，没有改成失焦隐藏。

## 滚动拼接

Ctrl+3 框选固定的正文范围。450 ms 周期采集新帧，估算向下滚动位移，只有重叠误差低且匹配位置明确才接入新条带。相同帧不重复追加，非重叠或重复图案不强行拼接。保留已接受条带，完成时一次组装 PNG，避免每帧复制整张长图。默认上限 3200 万像素。

控制条关闭阴影，并与选区保留额外距离。实窗测试曾发现系统阴影跨入选区导致匹配误差；修复后 160×335 输出与滚动测试源的每个像素一致。整屏选区没有控制条放置空间时，使用快捷键或托盘完成/取消。

当前只支持用户手动向下滚动，要求选择无固定页头和浮动内容的区域。匹配失败保持已有条带并提示，不支持强行拼接、水平、反向追加或自动滚轮。

## 视频

FFmpeg 独立进程使用 gdigrab 捕获物理选区，H.264 CRF 16、目标 30 fps、YUV 4:2:0，输出 MP4。只补齐奇数边长，不缩放画面。当前无音频和暂停。进度以实际编码帧为依据，启动进程不等同于成功。

每次录制分配独立临时文件，正常停止用 stdin `q` 等待封装，再重命名为最终 MP4。取消删除本次文件；退出应用前先完成正在录制的视频。Windows Job Object 的 `KILL_ON_JOB_CLOSE` 绑定编码进程，应用异常退出时不遗留编码器。打包的运行依赖、许可证与 SHA-256 在 `tools/ffmpeg/SOURCE.md`。

## 验证结果

- `go test .` 与 `go vet .`：布局、设置迁移、热键回滚、PNG 全像素、滚动去重和歧义拒绝通过。
- `go test -tags mediae2e -run 'TestRecorder|TestCancelledRecording|TestEncoderGuard' -v .`：318×240 MP4 可完整解码，录制取消无文件残留，关闭进程 Job 会终止编码器。
- `scripts/verify-media.ps1`：原生窗口生成确定性高频彩色滚动源；实际系统快捷键启动截图、贴图、滚动与录屏。160×200 PNG 和 160×335 长图逐像素相同；临时贴图、常驻切换、点击外部关闭通过；动画 MP4 为 318×240，94 帧，抽样帧哈希不同；退出录制中的应用仍保存可播放视频。
- `scripts/verify-capture.ps1`：后台截图、富文本粘贴、取消不改剪贴板、托盘、单实例和退出通过。

Windows 实机为单显示器 1920×1080。多屏、混合 DPI、长时间录制、低性能设备的实际帧率和浏览器动态内容仍需更广泛验收。

验证产物：`artifacts/control-panel-media.png`、`pin-resident-current.png`、`scroll-verification.png`、`recording-demo.mp4`。验证使用临时配置与 `artifacts/media-validation` 输出目录，未改动用户个人配置或全局 PATH。
