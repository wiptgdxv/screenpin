# 开发任务与里程碑

当前全部任务均为“未开始”。本文件是执行计划，不是进度报告。详细功能 ID 见 [功能对照与验收](功能对照与验收.md)。

## Gate 0：先证明基础技术可用

预计 1–2 周，作为是否采用 MyGo 原生 UI 的决策门槛。

| 任务 | 交付物 | 通过条件 |
| --- | --- | --- |
| G01 固定依赖和构建 | 精确版本与可复现构建脚本 | 新目录可构建，未使用移动的 main 或本机绝对 replace |
| G02 系统捕获探针 | 自制测试图 → 真屏幕 → 捕获 PNG | 选区边界和像素坐标相符，注明颜色转换限制 |
| G03 多显示器探针 | 屏幕列表、边界和 DPI 记录 | 负坐标、混合 DPI、竖屏正确；无实机时明确缺测 |
| G04 覆盖层探针 | 真桌面快照与拖动选区 | 不捕获自身遮罩，焦点和 Esc 退出正确 |
| G05 贴图探针 | 透明置顶、多窗口、穿透恢复 | 开关穿透后可恢复；移动跨屏不偏移 |
| G06 输入和剪贴板探针 | 中文文字输入与图片往返 | 常用聊天/办公应用可粘贴，透明 PNG 路径有说明 |
| G07 资源探针 | 100 次开关窗口的资源曲线 | 无持续句柄增长；退出无残留任务 |
| G08 技术决策 | 固定技术选型记录 | 对失败项列出原因、可接受修复或替代路线 |

Gate 0 只允许少量探针代码，不写大而全的设置系统。若跨屏/覆盖窗需要侵入式修改框架，先完成决定，再开始正式应用。

## M1：v0.1 日常可用的截图与贴图

依赖 Gate 0。任务顺序如下：

1. 建立 App 生命周期、单实例、托盘和全局动作注册；退出释放所有资源。
2. 固定坐标类型和图像资产模型；写混合 DPI、负坐标、裁剪边界和矩阵往返测试。
3. 实现抓取快照、框选、调整、放大镜、取色与取消。
4. 实现编辑文档和撤销命令；先做矩形、箭头、文字和不透明遮挡，形成可用链路。
5. 接入 PNG/JPEG 保存和剪贴板；再补荧光笔、铅笔、椭圆、折线、序号和模糊/马赛克。
6. 实现独立贴图窗口、拖动缩放、透明度、锁定、置顶和穿透恢复。
7. 完成基础设置：快捷键、默认输出、保存目录、文件命名和恢复默认。
8. 打包便携版本，完成从其他应用唤起到粘贴的真实使用验收。

验收输出：可运行 EXE、版本号、构建说明、10 个手工用例结果和操作录像。至少连续使用一周再进入“稳定可用”描述。编辑器不能只是画布效果演示。

## M2：v0.2 本地识别与资料管理

1. 建立 SQLite schema、迁移、资产文件布局、引用计数和容量限制。
2. 实现关闭/销毁/恢复、贴图组、历史缩略图和重新贴图。
3. OCR 技术探针：确定模型、语言、字典、推理后端、分发体积和运行时依赖。
4. 独立 OCR 任务与 worker，支持取消、失败反馈和缓存失效。
5. 绘制文字框，支持行/段落选择；复用几何模块处理缩放、旋转与裁剪。
6. 增加二维码识别、裁剪旋转、延时截图与多屏位置恢复。
7. 验证断网识别、重启恢复和模型缺失；发布完整离线包。

验收输出：明确的 OCR 样本结果、离线安装/使用记录、贴图与历史的状态转换说明。不能用云 OCR 替代“本地 OCR”但仍宣称已对齐。

## M3：v0.3 长截图

1. 建立可复现滚动帧语料：代码、网页、表格、聊天；另备固定页头、重复文本、动画和快速滚动反例。
2. 先实现连续两帧位移估计及置信度，再扩展到完整会话。
3. 片段图存储与预览，防止每次拼接拷贝整图。
4. 手动纵向滚动与匹配指示；拒绝低可信帧。
5. 回退、停止、重新开始与裁剪；定义反向滚动的行为。
6. 横向拼接、跨屏选区与资源限额；单独验证超长图的格式限制。
7. 逐条带导出与重开；失败时保留可恢复的会话信息。

验收输出：各类样本的缺失/重复/错位记录及失败处理说明。先保证不误拼，再追求更快或更长。

## M4：v0.4 快速 MP4 录制

1. 捕获后端能力探测；选择 GDI、DXGI 或 WGC 的第一条可用路径。
2. 建立独立的录制状态机、单调时钟、帧队列和进度。
3. FFmpeg 路径探测、进程管理、参数校验和错误输出收集。
4. 开始、暂停、继续、停止和取消；正常停止写出可播放文件。
5. 录制控制条不进入画面；分辨率变化与设备丢失明确处理。
6. 连续 30 分钟验收与文件中断恢复策略，记录丢帧和资源使用。

验收输出：固定参考设备上的 MP4 样片和性能报告；不得把 ffmpeg 进程成功启动作为录屏成功。

## M5：v0.5 普通录制和发布质量

1. 系统音频、麦克风以及统一时间线，分别覆盖设备切换和权限错误。
2. 可回放中间素材；GIF/WebP/MP4 导出与编码进度。
3. 鼠标、按键展示和录制中标注；各轨可开关。
4. 回放、倍速与保留连续区间的两端裁切。
5. 自动保存、磁盘配额、崩溃后清理和版本迁移。
6. 软件分发、依赖清单、可取消更新与回退验证。

验收输出：30 分钟音画同步记录、三种导出文件、安装/升级/卸载测试和已知限制列表。

## M6：高级功能逐项对标

按以下依赖顺序推进，每项单独立项和验收，不捆成一个不可完成的大版本：

| 顺序 | 功能 | 开始条件 |
| --- | --- | --- |
| 1 | 多类型贴图与分组增强 | 数据模型和文字渲染稳定 |
| 2 | UI 子元素检测、全局鼠标动作 | 基础热键和窗口坐标稳定 |
| 3 | 实时窗口贴图、多窗口捕获 | 持续捕获与窗口生命周期验证通过 |
| 4 | 翻译适配器 | 配置、取消、网络错误和用户授权流程明确 |
| 5 | 表格识别 | OCR 已稳定，结构模型和可核对样本可用 |
| 6 | 公式和文档识别 | 模型适配、版面顺序和导出格式设计明确 |
| 7 | 智能擦除、摄像头画中画 | 推理/媒体管线有余量且单独验收 |
| 8 | 脚本与自动化接口 | 业务动作已版本化，有明确运行边界 |
| 9 | Windows ARM64、macOS | 有真实测试设备，原生适配器逐项实现 |

## 每项工作如何提交和结束

建议一次改动包含一个可独立使用的行为、对应测试和简短说明。按 geometry、capture、editor、pin、ocr、stitch、record 依赖顺序拆分。先定义输入输出和错误，再写 UI。

完成记录模板：

```text
任务 ID：
实现提交：
支持平台与实际运行平台：
输入操作：
预期输出：
实际结果与文件：
异常测试：
资源/性能记录：
尚未支持：
```

对所有模块坚持同一规则：编译通过、单元测试通过、真实使用通过分别记录。没有验证的功能不得填“已完成”。
