# 玻璃界面重构方案

调研日期：2026-11-04。范围：截图工具的原生桌面界面，Windows、macOS、Linux。本文件是设计与接入计划，尚未实现新材质，也未验证第三方组件在本项目中的兼容性。

## 结论

保留 Go/MyGo 原生路线。优先组合：MyGo 系统 Vibrancy + 官方 Glass 插件 + 经兼容性验证的 Onevra 控件。uix 作为基础控件备选。先验证真正的桌面模糊，再统一控件，最后重排工作台，避免再次只改颜色。

## 当前为什么没有透明感

已检查本项目 main.go：主窗口背景为不透明 #E8EFFB，根布局还绘制 #E8EFFB 到 #F3F8F7 的不透明渐变，窗口没有配置 Vibrancy。已有 Glass 只能处理同一窗口内已经绘制的内容，所以浅色面板后面仍是浅色背景。

这属于应用当前的材质和绘制配置，不能据此认定框架有缺陷。全窗口 Opacity 会连文字、图标和图片一起变淡，不用于实现本方案。

## 三层材质分别负责什么

| 层级 | 能力 | 用途 | 边界 |
| --- | --- | --- | --- |
| 系统窗口背景 | MyGo WindowOptions.Vibrancy | 让桌面和后方窗口经过模糊后透进窗口边框区域 | 当前固定源码注明支持 macOS、Windows 11 22H2；Linux不承诺系统背板模糊 |
| 窗口内部玻璃 | 官方 plugins/glass | 工具栏、弹层覆盖图片或列表时，模糊其下内容并呈现边缘光泽 | 只能采样同一窗口内的内容，本身不能模糊桌面 |
| 基础控件 | Onevra，备选 uix | 统一按钮、菜单、设置、图标、间距和状态 | 组件库不会自动提供操作系统窗口透明效果 |

Windows 的 Acrylic 可以模糊桌面及后方窗口。Mica 是融合壁纸色彩的不透明材质，可作为更沉稳的外观选项，不能称为真正的桌面透明。

## 组件库选型

1. Onevra：优先验证其窗口外壳、FloatingButtonGroup、Settings 和 Lucide 图标。按本项目定制浅色中性主题，不直接采用其默认配色。先试装最小按钮、菜单和工具栏，不整体替换页面。
2. uix：提供原生 MyGo 的 shadcn 风格按钮、工具栏、弹层、颜色选择器等；若 Onevra 外壳或依赖不合适，采用 uix 基础控件配自有材质容器。
3. 官方 Glass：项目已具备，继续使用。重点调整其覆盖的真实内容、层级与背景；48 DIP 的小工具栏不要指望单独调 Clarity 就产生明显变化，官方说明该参数主要作用于较大面板。

兼容性检查：Onevra 当前 main 的 source/go.mod 依赖 MyGo v0.7.1，而本项目 replace 到本地固定快照。尚未确认 API 兼容，不直接 go get latest，不混用两个完整主题系统。验证失败时保留现有基础控件，系统材质验证仍可独立推进。

## 视觉与布局

方向：通透、轻盈、紧凑的截图工作台。主窗口保持 900×600 DIP 起始尺寸；窄窗口收起文字标签、使用溢出菜单，不持续扩大窗口。

- 顶栏：48 DIP，与窗口材质连贯，保留原生窗口按钮和拖动区域，消除单独白色横条。
- 左侧：56–60 DIP 的轻量导航，仅展示有实际功能的入口。
- 中央：主要面积留给图片。画布周边保持中性浅灰，不叠加彩色渐变；透明图片提供棋盘格背景。
- 底部：一条分组工具栏，包含缩放、适应、复制、保存、贴图；玻璃只做这一层，不在每个按钮外再套玻璃卡片。
- 设置、图像信息：按需展开，使用更厚的磨砂保证可读性，不常驻挤压画布。
- 贴图窗口：图片保持原始色彩与不透明度；只让细窄控制条使用玻璃，鼠标移开后收起控制条的交互需要单独实现与验证。

建议设计参数（起始值，不代表已验证的最佳值）：

| 参数 | 建议 |
| --- | --- |
| 文字 | #1F2933；辅助文字 #5E6978 |
| 强调色 | #2563EB，仅用于选中、焦点和主要操作 |
| 面板底色 | 中性白色叠层，强度按桌面实测调整；不同时叠多种彩色雾层 |
| 画布 | #F2F4F7，图片边界清楚 |
| 圆角 | 面板 14–16 DIP，工具栏 18–22 DIP，控件 6–8 DIP |
| 字体 | Windows 微软雅黑 UI；macOS 苹方；Linux 使用可用中文无衬线回退 |
| 文字尺寸 | 正文 13–14 DIP，辅助 12 DIP；不靠过淡颜色制造层次 |

## 多端策略

| 平台 | 计划 | 当前验证情况 |
| --- | --- | --- |
| Windows 11 22H2 及以上 | 先验证 Acrylic 背板；可增加 Mica 外观选项 | 本机为 Windows 11，符合源码注明的版本范围；尚未完成本轮材质实测 |
| macOS | 使用语义化 Vibrancy 材质，工具栏配 Glass | 仅核对接口与官方示例，需真机验收 |
| Linux | 默认实色或窗口内部 Glass；桌面透明与模糊视合成器另验 | 不承诺复现 Windows/macOS 的系统模糊 |
| 系统关闭透明效果或高对比度 | 使用清晰的实色背景，保留相同布局和操作 | 需实测材质回退与文字对比度 |

## 实施顺序与验收

第一步：做系统材质小样。只改窗口创建、根背景和一条工具栏，不升级依赖。Windows 必须在创建时配置材质，按 c.Vibrancy() 决定是否使用透明根背景；参照仓库 examples/vibrancy。拖动到不同窗口上观察真实背板，核对未激活、缩放、最大化、主题切换及标题栏。

第二步：在独立试验目录固定组件版本。验证 Onevra 最小控件与现有 MyGo 快照；必要时比较 uix。记录依赖差异后，再决定是否升级框架，避免让视觉改版变成未经验证的依赖替换。

第三步：接入统一控件，按上述布局重排工作台和贴图窗口。保留已有快捷键、复制、保存和贴图行为；未实现的截图、OCR 等功能不做可点击的假入口。

验收项目：

- 在浅色、深色以及复杂后方窗口上检查玻璃变化；区分系统桌面背板和窗口内部模糊。
- 白色照片、黑色照片、透明 PNG 均能清楚辨认；复制和导出的像素不受界面材质影响。
- 默认与最小窗口尺寸下无控件遮挡；系统标题按钮、拖动和贴图置顶可用。
- 键盘焦点、快捷键和禁用状态清楚；普通正文以 4.5:1 对比度为验收目标。
- 与旧版比较空闲 CPU、拖动/缩放时帧耗和 GPU 开销；尚无数据，不承诺性能提升。
- 构建通过和 GUI 运行验证分别记录，不将跨平台编译当作三端视觉验收。
